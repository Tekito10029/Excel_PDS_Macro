製造票用マクロ 運用ガイド

対象：Module1_V2.5.bas / Sheet3_V2.5.cls / Module2_V2.5.bas
このガイドは「現場で使う人向け」の手順書です。プログラムの知識は不要です。
最終更新：2025/11/26

1. 全体の使い方イメージと動作フロー
概要

1-1. マクロの役割

役割このブックのマクロは、主に次の 3 つのことを自動化します。

  1. Sheet3：コード変換＋装飾
    G～J列に品名を入力すると、D列の上段と下段に対応するコードが自動で入り、さらに製品寸法の単位などの「装飾」が自動で付きます。
  2. Module2：括弧＋ラベルの図形
    選択した行をまとめる「左中括弧」と、その説明ラベルを図形で一括作成／削除できます。別シートへのミラーも可能です。
  3. Module1：マスタ更新とトラブル復旧
    外部マスタを読み込み直したり、イベントが止まったときの復旧（Fix_EnableEvents）を行います。
1-2. 動作フロー（全体）

日常運用の大まかな流れは次のとおりです。

① ブックを開く
→
② マスタ更新
（必要時のみ）
→
③ Sheet3 に入力
→
④ 自動変換＋装飾
→
⑤ 括弧＋ラベル作成
（必要な行に）
→
⑥ 印刷・出力

ポイント：通常は ③～⑥ のループです。②（マスタ更新）は、マスタ変更時だけ実施すればOKです。

2. 初期設定・マスタ更新（担当者向け）
事前準備
2-1. マスタファイルの場所
  • 装飾ルールマスタ："製造\0⃣.沓\00.製造表 各社\DecorMaster.xlsx"※DecorConfig 用の外部ブック。
  • 参照マスタ（沓用コード表）："製造\0⃣.沓\00.製造表 各社\沓用コード表.xlsx"RefCache 用の外部ブック。

初回だけ、マクロ実行時にファイル選択画面で場所を指定します。2 回目以降は自動で同じ場所を参照します。

2-2. 装飾ルール（DecorConfig）の更新手順
  1. このブックを開きます。
  2. シートに配置されている装飾リスト更新のボタンを押します。
    ※もしくはExcel のメニューから 開発タブ → マクロ を開きます。（ショートカット：Alt + F8）
    その後マクロ一覧から UpdateDecorConfigFromFile を選び、「実行(R)」を押します。
  3. 初回のみ、装飾マスタのファイルを選択します。
  4. 「装飾ルール(DecorConfig)を更新しました。」というメッセージが出たら完了です。

タイミング：装飾ルールを変更・追加したとき（例：新しい注意書きルールを入れたとき）に実行してください。

2-3. 参照マスタキャッシュ（RefCache）の更新手順
  1. シートに配置されているコードリスト更新のボタンを押します。
    ※もしくはAlt + F8 でマクロ一覧を開きます。
    その後UpdateRefCacheFromRefFile を選び、「実行」をクリックします。
  2. 初回のみ、参照マスタ（沓用コード表）のファイルを選択します。
  3. 処理が終わると、ブック内の RefCache シートに最新のマスタがコピーされます（シートは非表示のまま）。

タイミング：沓用コード表に新しい品番が追加されたとき、名称が変わったときなどに実行してください。

2-4. まとめて更新する場合
  1. シートに配置されているコードリスト更新のボタンを押します。
    ※もしくはAlt + F8 でマクロ一覧を開きます。
    その後UpdateAllMasterCaches を選び、「実行」をクリックします。
  2. 装飾ルールと参照マスタを、続けて両方更新します。

ブックを配布する前や、マスタをまとめて変更した後は、このマクロを使うと便利です。

3. Sheet3 の使い方（コード変換＋装飾）
日常作業
3-1. 入力する範囲
  • Sheet3 の 6～19 行が対象です。
  • 2 行で 1 セット（例：6 行目＝上段・7 行目＝下段）という単位で動きます。
  • G～J列（右側）：製品名を入力します。その後下段には寸法の単位などの装飾が付きます。
  • D列（左側）：製品名から自動で検索結果が入り、コードの上2桁を上段に、下3桁を下段に入力します。

注意：6～19 行以外で入力しても、このマクロは動きません。

3-2. 右から左への変換
  1. G～J列の上段（例：6 行目）に、変換元となる文字列を入力します。（結合セルの場合は代表セルに入力します）
  2. 入力確定後、自動で左側 D列 上段／下段にコードが分解されて表示されます。
  3. マスタに無い場合：
    • D列の上段に 62、下段に 018 など、あらかじめ決められた「未対応コード」が入ります。

注意：右側の下段だけを変更しても変換は行われません。必ず「上段（例：6行目）」を編集してください。

3-3. 装飾のイメージ
  • 装飾は、主に右側の下段セルに表示されます。
  • 内容は DecorConfig シートで定義されています。
    • 特定の文字・記号が含まれているときに寸法に「φ」や「w」といった文言を自動で付けることができます。
    • 一部のルールは「除外」指定があり、その場合は装飾を付けないようになっています。

装飾がおかしいと感じたら：
装飾ルールが格納されている DecorConfig シートか、マスタ自体の設定を確認してください。ルール追加後は UpdateDecorConfigFromFile の再実行も必要です。

4. 括弧＋ラベル図形の使い方（Module2）
ラベル図形
4-1. 括弧・ラベルの作成。その後他シートにもコピー（ミラー）
  1. 括弧でまとめたい行を、列方向まで含めて選択します。
    （例：行 6～10 の A～F 列をドラッグして選択）
  2. シートに配置されているラベル作成のボタンを押します。
    ※もしくはAlt + F8 でマクロ一覧を開きます。その後DrawLeftBrace_Label_One_WithMirror を選び、「実行」をクリックします。
  3. ラベル文字列の入力ボックスが表示されるので、説明文（例：「○○工程」）を入力して OK を押します。
  4. 選択範囲の左側に「左中括弧」と、その左側にラベルが表示されます。

    5. メモ：ラベル文字列はセルにも保存されます。区切り文字（- / , など）付きで追記されるため、あとから一覧のように確認できます。

  5. 設定されているミラー先シート（例：「製造票 ③ (現場用)」など）にも、同じ位置・同じラベルの括弧が自動で作成されます。
  6. 同じシートの 30～43 行側にも、同じレイアウトで括弧＋ラベルがコピーされます（設定で有効になっている場合）。

ミラー先のシート名はマクロ内の設定で管理されています。運用ルールの変更（ミラー先の追加など）が必要な場合は、担当者に相談してください。

4-2. 括弧とラベルを削除する

シート全体の括弧＋ラベルを消す

  1. 対象シートをアクティブにします。
  2. マクロ一覧から DeleteAllBracesAndLabels_ActiveSheet を実行します。
  3. そのシート上の括弧図形と、関連するセルラベルがすべて削除されます。

ミラー分もまとめて削除する

  • 全シート対象：DeleteAllBracesAndLabels_WithMirror
  • 選択範囲のみ対象：DeleteBracesAndLabels_SelectedRange_WithMirror

注意：削除マクロは元に戻す（Ctrl+Z）が効きにくい場合があります。念のため、重要なシートはバックアップを取っておくと安心です。

4-3. =TEXT(K4,"d") を書き込む補助マクロ
  • Write_TEXT_K4_dd_ToTarget：指定セルに =TEXT(K4,"d") を書き込みます。
  • DeleteAllBracesAndLabels_AndWriteTEXTdd：シート上の括弧＋ラベルを全削除したあと、同じく =TEXT(K4,"d") を書き込みます。
  • DeleteBracesAndLabels_SelectedRange_AndWriteTEXTdd：選択範囲だけ削除したあとに、式を書き込みます。

どのセルに書き込むかは、マクロ内の TARGET_NAMED_RANGE や TARGET_CELL_ADDR の設定によって決まります。

5. トラブルシューティング
困ったとき
5-1. 自動変換が動かない場合
  1. 入力している行が 6～19 行 か確認します。
  2. D列の 上段行 に入力しているか確認します。
  3. Excel のメッセージバーに「マクロが無効」などの表示がないか確認します。
  4. それでも動かない場合：
    • 担当者に Fix_EnableEvents マクロを実行してもらってください。

イベントが無効になっている場合：
他のマクロの途中エラーなどで Application.EnableEvents が False のままになることがあります。その復旧専用が Fix_EnableEvents です。

5-2. 「RefCacheがありません」と表示される
  1. 担当者に、UpdateRefCacheFromRefFile を実行してもらってください。
  2. 参照マスタファイルの場所が変わった場合は、再度ファイル選択画面で正しいファイルを選択します。
  3. 更新後に Sheet3 で再度入力して、変換されるか確認します。
5-3. 装飾が期待どおりに付かない
  1. 最近 DecorConfig マスタを変更していないか確認します。
  2. 変更した場合は UpdateDecorConfigFromFile を実行して、ルールを再読み込みしてください。
  3. それでもおかしい場合は、DecorConfig の該当行（ルール）を確認し、文字列やオプションに誤りがないかをチェックします。

より詳しく確認したい場合は、開発者用マクロ TraceDecorAtRow_Active で、どのルールがヒットしているかを見ることもできます。（通常ユーザーは不要です）

6. 運用ルールのおすすめ
運用ルール
  • 権限分け：
    • 一般ユーザー：Sheet3 への入力、括弧ラベル（Module2）の実行のみ。
    • 担当者：マスタ更新（Update～ 系）と復旧（Fix_EnableEvents）。
  • 定期メンテナンス：
    • 月 1 回程度、マスタファイルが最新か確認し、UpdateAllMasterCaches を実行。
  • バックアップ：
    • 括弧ラベルの大量削除やマスタの大幅変更前には、ブックをコピーしてバックアップを取る。

この運用ガイドを印刷してファイルに綴じる場合は、「仕様書」とセットで保管しておくと、トラブル時の調査がスムーズになります。
