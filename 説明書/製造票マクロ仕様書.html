1
全体概要
1-1. 機能概要
機能一覧
名称 製造票用コード変換・装飾マクロ
目的 製造票の左側・右側コードの変換、装飾文字列の自動付与、および括弧＋ラベル図形の描画を自動化し、作業ミス削減と入力効率向上を図る。
構成
  • Module1：マスタ更新・診断・ユーティリティ。
  • Sheet3：コード変換・装飾ロジック（Worksheet_Change イベント）。
  • Module2：括弧＋ラベル図形／セルラベル管理・ミラー機能。

処理フロー

実運用では、先にマスタを最新化し、その後は Sheet3 上の入力に応じて自動変換・装飾が行われます。括弧＋ラベル機能は必要な行に対して任意に実行します。

シート・モジュール構成
2-1. シート構成
構成
Sheet3
  • 対象行：6～19 行（2 行 1 セット：偶数＝上段／奇数＝下段）。

  • 列 A～C 使用（A:3→4キー, B:4→3キー, C:タグ）。
  • 通常は非表示（xlSheetHidden）。

3
Module1 の仕様（マスタ更新／ユーティリティ）
3-1. 主な定数・パス設定
定義
  • 装飾マスタ関連
    • DECOR_CFG_PATH_NAME：装飾マスタパス用の名前定義キー。
    • DECOR_CFG_DEFAULT：装飾マスタ既定パス。
    • DECOR_CFG_SHEET：装飾マスタ／運用ブック側シート名（通常 "DecorConfig"）。
  • 参照マスタ関連
    • REF_CFG_PATH_NAME：参照マスタパス用名前定義キー。
    • REF_CFG_DEFAULT：参照マスタ既定パス。
    • REF_SOURCE_SHEET：元マスタシート名（例："沓用コード"）。
    • REF_CACHE_SHEET：キャッシュシート名（"RefCache"）。
3-2. 主な処理
処理仕様

3-2-1. パス取得・保存

  • GetDecorCfgPath / GetRefCfgPath
    • 名前定義 → 既定パス → ファイルダイアログの順で有効なパスを決定する。
  • SavePathToName / LoadPathFromName
    • 名前定義を利用したパス文字列の保存・取得を行う。

3-2-2. マスタ更新

  • UpdateDecorConfigFromFile
    • 装飾マスタブックを開き、シート DecorConfig の A1:G最終行を運用ブック側へ転記。
  • UpdateRefCacheFromRefFile
    • 参照マスタ（沓用コード）を開き、C/D/E 列を RefCache に A/B/C としてキャッシュ。
  • UpdateAllMasterCaches
    • 上記 2 つの更新処理を連続実行するラッパーマクロ。

3-2-3. 診断・復旧

  • DumpDecorRules / Debug_DecorRulesSummary
    • 装飾ルール内容や件数を Immediate ウィンドウに出力し確認する。
  • TraceDecorAtRow_Active
    • アクティブシートを対象に、指定行の装飾マッチ状況をトレースする。
  • Fix_EnableEvents
    • Application.EnableEvents を True に戻し、計算モードなどを復旧する。
    • エラーが発生しても、必ずイベント有効状態で終了する。

Sheet3 の仕様（自動変換・装飾）
4-1. 対象範囲・基本定義
対象
対象行 6 ～ 19 行（2 行 1 組）
左側列 D列（列番号 4）
右側列 G ～ J 列（列番号 7 ～ 10）
イベント Worksheet_Change(ByVal Target As Range)
マスタ
  • 変換マスタ：RefCache シート（3→4／4→3 マップ）。
  • 装飾マスタ：DecorConfig シート（A～G列）。
4-2. Worksheet_Change 処理フロー
処理フロー 
Private Sub Worksheet_Change(ByVal Target As Range)
  1. 前処理
    • エラーハンドリング設定（CleanUp ラベル）。
    • Application.EnableEvents = False / ScreenUpdating = False。
  2. マップ構築
    • BuildMapsFromCache(map34, map43) で RefCache から辞書を構築。
    • キャッシュが無い／空の場合は、初回のみ MsgBox 通知後処理中止。
  3. セル単位処理
    • Target.Areas を展開し、各セルで RouteOneCell を実行。
  4. 後処理
    • ScreenUpdating / EnableEvents を必ず True に戻して終了。

注意：イベント無効のまま終了してしまった場合は、Module1 の Fix_EnableEvents を手動実行して復旧します。

4-3. 右（G～J）→左（D列）変換
変換仕様
  • トリガ：G～J列（上段行）の値変更。
  • 処理概要：
    1. 結合セルの代表セル（上段）を GetRowMergeTopLeft で取得。
    2. 値を正規化しキーを作成。
    3. キーが空の場合：
      • WriteLeftSplit で D列上段／下段をクリア。
      • 装飾もクリア。
    4. キーあり：
      • Resolve_OR_WithKey で map43（4→3）から候補検索。
      • ヒットなし：
        • WriteLeftFallback により、上段へ UNMATCHED_LEFT_UPPER、下段へ UNMATCHED_LEFT_LOWER を設定。
        • 装飾はクリア。
      • ヒットあり：
        • WriteLeftSplit で D列上段／下段へ変換値を分割書き込み。
        • ApplyDecorations で装飾を付与。
4-4. 装飾ルール適用（ApplyDecorations）
装飾仕様 
Private Sub ApplyDecorations(ByVal topRow As Long, ByVal matchedKeyRaw As String)
  • 対象セル：
    topRow に対応する 2 行セットの下段行・右側装飾セル。
  • 処理概要：
    1. 装飾対象文字列 srcNorm を組み立て（左・右・キーを連結・正規化）。
    2. BuildDecorRules で DecorConfig からルール一覧を取得。
    3. 既存装飾の処理：
      • DECOR_CLEAR_BELOW_FIRST = True の場合は空文字から構築。
      • それ以外は StripDecorations で既存の before/after を除去。
    4. 除外ルール（exclude）にマッチした場合：
      • 既存装飾のみを削除し、新規装飾は付けず終了。
    5. 専用ルール（exclusive）が存在する場合：
      • 該当ルールのみを対象として評価。
    6. 各ルールについて、before/after/text を評価し、重複しないよう AppendUnique で蓄積。
    7. 最終的に [前装飾] + baseText + [後装飾] をセルへ書き戻す。
5
Module2 の仕様（括弧ラベル・ミラー機能）
5-1. 主な定数
定義
  • 括弧・ラベル外観
    • 線の太さ：BRACE_WEIGHT_PTS
    • ラベル文字サイズ：LABEL_FONT_SIZE
    • 括弧幅：BRACE_WIDTH
    • 括弧とラベルの位置関係：LABEL_X_OFFSET
  • ラベル書き込み先
    • WRITE_WHERE = 1：名前付き範囲 → 固定セルの順で書き込み。
    • WRITE_WHERE = 2：選択範囲左上セルに書き込み。
  • ミラー機能
    • MIRROR_ENABLED：他シートへのミラー出力有無。
    • MIRROR_SHEETS：ミラー先シート名の一覧。
    • LOCAL_MIRROR_ENABLED：同一シート内（6～19 → 30～43）ミラー有無。
5-2. 主な公開マクロ
処理仕様

5-2-1. 括弧＋ラベル描画

  • DrawLeftBrace_Label_One
    • 選択範囲に 1 本の左中括弧とラベル図形を描画。
    • ラベル文字列は InputBox で入力（前回値を初期値として再利用）。
    • WriteLabelToCell により、対象セルへ区切り付きで追記。
  • DrawLeftBrace_Label_One_WithMirror
    • 上記に加え、ミラー設定に従い他シート・同一シート別エリアへも括弧＋ラベルを描画。

5-2-2. 図形・ラベル削除

  • DeleteAllBracesAndLabels_ActiveSheet：アクティブシートの括弧図形・ラベルを全削除。
  • DeleteBracesAndLabels_SelectedRange：選択範囲に紐づく括弧図形・ラベルのみ削除。
  • DeleteAllBracesAndLabels_WithMirror：現在シート＋ミラー先シートの図形・ラベルを全削除。
  • DeleteBracesAndLabels_SelectedRange_WithMirror：選択範囲と同じ矩形をミラー先にも作り、その範囲のみ削除。

5-2-3. =TEXT(K4,"d") 関連

  • Write_TEXT_K4_dd_ToTarget：対象セルに =TEXT(K4,"d") を設定。
  • DeleteAllBracesAndLabels_AndWriteTEXTdd：
    • 図形・ラベル全削除後、=TEXT(K4,"d") を書き込む。
  • DeleteBracesAndLabels_SelectedRange_AndWriteTEXTdd：
    • 選択範囲に対応する削除後、=TEXT(K4,"d") を書き込む。
6
想定運用フロー
6-1. 運用手順（概要）
運用
  1. 初期設定・マスタ更新
    • Module1 の UpdateDecorConfigFromFile を実行して装飾ルールを更新。
    • UpdateRefCacheFromRefFile を実行して参照マスタキャッシュを更新（または UpdateAllMasterCaches）。
  2. Sheet3 でのデータ入力・自動変換
    • D列または G～J列上段にコードを入力する。
    • 対応する左⇔右コードが自動変換され、必要に応じて装飾が付与される。
  3. 括弧＋ラベルの付与・確認
    • 対象範囲を選択し、Module2 の括弧描画マクロを実行。
    • 必要に応じてミラー機能で他シート・別エリアにも反映。
  4. 不要になったラベル／括弧の整理
    • 削除系マクロを実行して、不要な図形・ラベルを一括または範囲指定で削除。
  5. トラブル発生時
    • 自動変換が動作しない場合：RefCache の更新状況と EnableEvents を確認。
    • イベント無効の疑いがある場合：Fix_EnableEvents を実行。
